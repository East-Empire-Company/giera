# Giera Xbox UWP probe

Minimal Xbox-targeted UWP host that loads a capability probe page through a packaged local stream. It answers one question before any game wrapper exists: can the Xbox UWP `WebView` run Giera's renderer and platform APIs?

Plan: `thoughts/shared/plans/2026-10-28-xbox-dev-mode-giera.md` (Phase 2).

## What it checks

| probe key | proves |
|---|---|
| `location` | page origin under `ms-local-stream`, user agent, DPR, screen size |
| `es2022` | class private fields, brand checks, `Object.hasOwn`, `Array.at`, `structuredClone`, `??=`, error `cause`, `d` flag, top-level await |
| `webgl2` | WebGL2 context, limits, extensions, and a real shader link + `readPixels` colour check |
| `moduleImport` | dynamic `import()` of a packaged ES module |
| `fetchRootAbsolute` / `xhrRootAbsolute` | root-absolute `/Assets/...` requests from a local-stream page |
| `imageLoad` | `Image` decode of a packaged PNG (Three texture path) |
| `moduleWorker` | `new Worker(new URL(...), { type: 'module' })` plus `fetch` inside the worker |
| `gamepads` | `navigator.getGamepads()` visibility and live button/axis values |
| `fps` | `requestAnimationFrame` rate over 2 s |
| `storage` | `localStorage` and `indexedDB` |
| `audio` | `AudioContext` state after a click/`A` press on the unlock button |

The page posts every result to the host through `window.external.notify`; `MainPage` shows the JSON in the overlay `TextBlock` at the bottom of the screen.

## Build (Windows host)

Requires Visual Studio 2022 with the Universal Windows Platform workload and Windows SDK 10.0.14393+.

```powershell
powershell -ExecutionPolicy Bypass -File build-probe.ps1
```

The script creates a self-signed `CN=Giera Xbox Probe` certificate on first run, exports `Giera.XboxProbe_TemporaryKey.pfx` (password `probe-dev-pass` by default, override with `-Password`), then builds Release x64 and prints the `.appx` path under `AppPackages\`.

## Deploy (console in Developer Mode)

The console and the deploying machine must be on the same local network. Dev Home on the console shows the console address and the Device Portal credentials. Then:

```sh
CONSOLE=192.168.1.50 PORTAL_USER=<user> PORTAL_PASS=<pass> ./deploy-xbox.sh install
```

Launch **Giera Xbox Probe** from Dev Home. The probe writes its JSON to the package's local folder, so the result is readable without a screen:

```sh
CONSOLE=192.168.1.50 PORTAL_USER=<user> PORTAL_PASS=<pass> ./deploy-xbox.sh result
```

If the console rejects the signature, install `Giera.XboxProbe_TemporaryKey.pfx` (password `probe-dev-pass`) into the console's trusted people store, or deploy with `WinAppDeployCmd install -file <appx> -ip <console-ip> -pin <dev-home-pin>` from a Windows machine on the same network, which installs the developer certificate for you.

## Stop conditions

- `webgl2.context` is `null`, or `webgl2.renderOk` is false → stop. Report the blocker; do not downgrade Three.js or switch distribution model.
- `gamepads.count` stays 0 with a controller connected → controller input needs a host-side route before packaging the game.
- `moduleWorker` errors while `moduleImport` works → the game's worker needs a classic-worker or inline fallback.
