# Giera Art Pass Implementation Plan

> **For agentic workers:** Use test-driven development. Preserve the current dirty worktree.

**Goal:** Unify the voxel scene's visual style and add grounded lighting, terrain shading, foliage motion, and tactile feedback without changing gameplay rules.

**Architecture:** Keep world generation, collision, and interactions voxel-driven. Use existing terrain, atlas, sky, instancing, and VFX systems; extend shader hooks and update paths. Migrate the post stack to pmndrs `postprocessing` plus N8AO as explicitly requested, preserving both split-screen views and the adaptive-quality path.

**Tech Stack:** TypeScript, Three.js r186, pmndrs `postprocessing`, `n8ao`, Vitest, Playwright.

**Spec:** User art brief, `history://current/full:246625-246724`.

## Global Constraints

- Preserve voxel world generation, collision, mining, crafting, NPC behavior, LAN protocol, and saves.
- Preserve existing user edits in `src/main.ts`, player/NPC files, QA scripts, and tests.
- Treat Xbox 60 FPS as a hard design target, not a verified claim; collect host solo/split frame-time evidence.
- Keep all ordinary-play VFX enabled and deterministic; bound instance and particle counts.
- Keep child-facing interactions visual-first; use icons for transient prompts instead of text-only world labels.
- Reuse installed KayKit, Quaternius, Kenney, and Poly Haven assets; add only libraries required by explicit requests.

## Recommendation Coverage

| Recommendation | Decision |
|---|---|
| Smooth terrain normals | Implement shared slope normals for duplicated smooth-top vertices, including chunk borders; keep hard voxel walls and collision. |
| Grass/cliff triplanar mapping | Blend existing atlas grass-top/grass-side tiles by world-space normal; apply only to terrain materials. |
| Stylized bark and cel palette | Replace high-frequency PBR oak bark with a warm flat stylized color; retain pixelated log ends. Use the current low-poly asset palette rather than globally toon-shading every model. |
| Hemisphere, sun, shadows, CSM | Retained. Official Three r186 `CSM`, 2 practical cascades at 1024², shadow range capped at 128 blocks (`shadowDistanceFor`), terrain chunks cast only within 80 blocks of a player (`WorldRenderer.updateShadowCasters`, refreshed on chunk crossing or split toggle, honouring both split-screen players). `PCFShadowMap` because r186 removed `PCFSoftShadowMap`. CSM's stock `lights_fragment_begin` replacement dropped r186's PBR energy terms (`material.dfg`, `multiScatteringCompensation`), which killed specular on every standard material; `spliceStockPrelude` keeps the stock prelude and takes only CSM's directional tail, and `dispose()` restores both global chunks. **Measured on the Mac Studio host** (headed Chromium, Metal/ANGLE, 1280×720, seed 424242), real-time, full desktop streaming radius (5,445 chunk meshes), solo: baseline HEAD 50 fps; 3 cascades @512 with every chunk casting 33 fps; final 52 fps. Under `?qa=1` the fixed 1/60 timestep blinds the auto-degrade ladder, so qa-mode fps understates real play; the pipeline's perf stage loads radius 8 and is not representative of desktop radius 20. **Not verified:** any Xbox hardware, split-screen at full radius after the final change, and sustained 60 fps. |
| Sky gradient and distance fog | Keep existing Three.js Sky and FogExp2; tune horizon/fog color so distant terrain blends with the sky. |
| ACES and bloom | Keep existing ACES and add subtle bloom at the requested luminance threshold. |
| pmndrs postprocessing and N8AO | Migrate from Three EffectComposer/GTAO to pmndrs EffectComposer/EffectPass and N8AOPostPass; retain grade, SMAA, resize/dispose, split composition, and quality controls. |
| Custom shader modification | Use existing `onBeforeCompile`; do not add `three-custom-shader-material`. |
| Foliage wind and grass blades | Animate existing instanced plants and voxel leaves; add one deterministic low-poly InstancedMesh of 3-triangle blades with a bounded density. |
| Yuka | Exclude the package: seeded NPC wandering, bounded walkTo, and parrot bob/turn already exist. Do not replace existing movement logic. |
| Hit/pop response | Keep existing item-drop pop/magnet. Add a localized tree/log hit response and wood/leaf debris without changing mining timing. Avoid GSAP/Tween.js. |
| Particle VFX | Extend the existing 64-sprite pool for wood/leaf hits, grounded footsteps, and sparse pollen. Ambient emissions must never evict gameplay bursts. Avoid Three.Quarks. |
| World-space prompts | Add a world-projected log-icon + count pickup cue using existing HUD projection; retain NPC speech bubbles. Exclude Troika text because pre-reader players need icons. |
| Asset repositories/animation | Keep installed CC0 KayKit, Quaternius, Kenney, and Poly Haven assets and KayKit clips. Exclude new Poly Pizza/Pmndrs/Mixamo/MagicaVoxel downloads because matching assets/animations already exist. |

## Review Focus

- Smooth-top normals must match at duplicated vertices and across chunk borders; flat terrain stays level.
- Terrain receives character/vegetation shadows without changing voxel collision or making chunk rebuilds expensive.
- N8AO and merged effects compile and render in solo and split-screen with correct per-camera depth, sizing, and color output.
- CSM, if retained, must update each camera's cascades before its split render and preserve both views.
- Vegetation remains deterministic, bounded, and cheap to rebuild; ambient particles cannot starve action VFX.

### Known open items (not fixed; reviewer-confirmed or measured)

- Split-screen streaming loads chunks around Player 1 only (pre-existing at HEAD); a far-away Player 2 can see unloaded terrain. Needs `loadArea` to take several centres.
- Decor is not world-anchored (offsets move with the 8-block recentre), does not react to `setBlock`, and floats up to ~0.75 blocks on smoothed slopes. Pre-existing for tufts/rocks; blades inherit it.
- `setBlock` remesh omits diagonal (corner) chunks and the +Y reach for smooth vertices; a one-vertex step is possible after an edit near a chunk corner.
- Full-radius desktop (radius 20) solo is about 48-52 fps on this host with AO/bloom ladder settling off; it is not 60. Split-screen at full radius was last measured before the final changes at 11 fps (before the 80-block caster range, 2 cascades and back-off) and was not re-measured after them.
- Chunk-border `castShadow` is decided by player position at 16-block cell crossings with a 16-block hysteresis; long low-sun shadows from chunks beyond 80+16 blocks are dropped.
